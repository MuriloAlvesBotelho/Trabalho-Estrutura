# Trabalho-Estrutura
Notação Big-O

Notação Big-O representa um limite superior assintótico (asymptotic upper bound).  
Dizemos que uma função T(n) é O(g(n)) se, e somente se, existirem duas constantes positivas c > 0 e n0>=0, tal que:

0<=T(n) <= c.g(n), An>n0

Isso garante que, a partir de um volume mínimo de dados n0, o custo computacional do algoritmo nunca ultrapassará a curva delimitada por $c \cdot g(n)$, permitindo desconsiderar constantes e termos menores para focar na taxa de crescimento assintótico.
